# How to Use

## Install Node.js

- **Node version:** `18.17` or higher
- **NPM version:** `9.6.7`

## Особливості

- проекти испоьзуеться redux-toolkit для созрарнения продуктов в корзину. Но запрос на свервер происходть при помощи методы fetch потому что запрос происодит на серверной стороне. Сделано для индексации магазина поисковыми роботами. Если такой необходимости нет то функциона можно переделать на использование RTK-Query создание при помощи createApi структура для возврата хуков какие дают возможность делать query или mutation

## Для запуску проекту у режимi розробки

### Встановiть залежностi

```bash
npm i
```

### зупастыть проект у режимi розробки

```bash
npm run dev
```
